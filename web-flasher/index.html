Flash ESP32RET

Connect the board over USB. Use Chrome or Edge (Web Serial). The installer picks ESP32 vs ESP32-S3 from the chip.

Hold BOOT if the port does not appear, then click Connect.

After install, the serial console is 1000000 baud. Set board type if needed:

  • SYSTYPE=0 Macchina A0
  • SYSTYPE=1 EVTV ESP32
  • SYSTYPE=2 Macchina 5-CAN
  • SYSTYPE=3 EVTV ESP32-S3
